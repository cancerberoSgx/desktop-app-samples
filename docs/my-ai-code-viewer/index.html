Features

Every project, every tool

Lists every folder you've run Claude Code or OpenCode in, with conversation count and last activity. A folder used with both tools shows up once, with both tools' conversations together.

Readable conversations

Your prompts and the assistant's replies as a chat; tool calls, tool results and thinking collapsed to a one-line preview you can click to expand. Subagent threads appear nested under the conversation that spawned them.

Never loses history

Claude Code deletes transcripts after ~30 days by default. Every conversation the app sees is archived into its own local SQLite database, so it stays readable after the original is gone.

Per-conversation stats

Model, duration, prompt and tool-call counts, input/output/cache tokens, cost, git branch and which tools were used, at the top of every conversation and as sortable columns.

Jump back in

Copy a ready-to-paste claude --resume / opencode --session command, open the project folder, or open the raw transcript.

Live and incremental

Rescans in the background every minute, only re-reading conversations that actually changed, so active sessions show up without a restart.

Quick start

Grab a binary above, or run it from source.

git clone https://github.com/cancerberoSgx/desktop-app-samples.git
cd desktop-app-samples/my-ai-code-viewer
python3 -m venv .venv
source .venv/bin/activate      # Windows: .venv\Scripts\activate
pip install -r requirements.txt
python3 main.py
