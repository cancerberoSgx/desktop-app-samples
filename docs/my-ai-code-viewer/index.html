My AI Code Viewer

Every project and conversation you've had with Claude Code and OpenCode, in one place: pick a folder, pick a conversation, read it. Archived locally, so old sessions don't vanish when the CLI prunes them, with stats on how much you use each agent, project and tool.

Features

Every project, every tool

Lists every folder you've run Claude Code or OpenCode in, with conversation count and last activity, filterable by tool or name. A folder used with both tools shows up once, with both tools' conversations together.

Readable conversations

Your prompts and the assistant's replies as a chat, with replies rendered as markdown (code blocks, tables, lists). Tool calls, tool results and thinking are collapsed to a one-line preview you can click to expand, and subagent threads appear nested under the conversation that spawned them.

Outline and Q&A only

An outline of every prompt jumps straight to it and highlights where you are as you scroll. "Q&A only" hides everything except your prompts and the final answer of each turn, so a three-hour session reads in a minute.

Usage stats

File > Stats opens charts and sortable tables: how much you use each agent, your top projects by cost, tokens, conversations or prompts, conversation length, thinking and tool-call counts, the most used tools and their error rates, and when in the week you prompt. Filter by date range and agent; double-click any project or conversation to open it.

Never loses history

Claude Code deletes transcripts after ~30 days by default. Every conversation the app sees is archived into its own local SQLite database, so it stays readable (and counted in the stats) after the original is gone.

Per-conversation details

Model, duration, prompt and tool-call counts, input/output/cache tokens, cost, git branch and which tools were used, at the top of every conversation and as sortable columns in the list.

Jump back in

Copy a ready-to-paste claude --resume / opencode --session command or the session id, open the project folder, or open the raw transcript, from the Actions menu or the Conversation menu.

Export as HTML

Save a conversation and its subagents as one self-contained HTML page that works offline: outline, search, light/dark theme, copy buttons on code, and the same Q&A / expand / markdown toggles, flipped in the browser.

Live, incremental, themed

Rescans in the background every minute, only re-reading conversations that changed, so active sessions show up without a restart. Follows your desktop's light/dark preference, or force either one.

Quick start

Grab a binary above, or run it from source.

git clone https://github.com/cancerberoSgx/desktop-app-samples.git
cd desktop-app-samples/my-ai-code-viewer
python3 -m venv .venv
source .venv/bin/activate      # Windows: .venv\Scripts\activate
pip install -r requirements.txt
python3 main.py
