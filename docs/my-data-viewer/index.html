Features

Instant SQL, no import step

Point at a CSV or JSON file (or just drag-and-drop it onto the window) and it's immediately queryable — DuckDB registers it as a table in memory, so there's no load/import wait, even before you run a single query.

Real SQL editor

A syntax-highlighted editor runs arbitrary SQL against your data — filters, ordering, whatever DuckDB supports — with results shown in a grid, not a wall of CSV text.

Schema browser

See exactly what tables, columns and indexes are available before you write a query, instead of guessing column names from a raw file header.

Saved queries

Name and keep multiple queries per datasource. Closing the app with unsaved edits prompts you to save or discard them, so nothing gets lost by accident.

Export to Parquet

Export a query's results, or just the schema, straight to a Parquet file for use in another tool or pipeline.

Profiles

Group datasources into profiles so unrelated projects don't clutter each other's list — switch the active one from the Profiles screen.

Connect to PostgreSQL, not just files

Add a datasource backed by a live PostgreSQL database — via a connection URL or individual host/port/user/password fields — and get the exact same schema browser, SQL editor and Parquet export as a CSV or JSON file.

Infer and lock in column types

"Infer types" sniffs a CSV/JSON file's columns and lets you review or correct them in a grid before saving — those types are then reused on every future query instead of being re-guessed each time.

Point-and-click browsing, no SQL required

The Data tab lets you sort by clicking a column header and add =/LIKE filters per column from dropdowns, paging through results — all pushed down into generated SQL automatically, for whenever you don't want to write a query by hand.

Excel-like result grid

Click, Ctrl-click or Shift-click to select cells, whole rows or whole columns, then Ctrl+C to copy the selection as tab/newline-separated text — ready to paste straight into a spreadsheet.

Quick start

Grab a binary above, or run it from source.

git clone https://github.com/cancerberoSgx/desktop-app-samples.git
cd desktop-app-samples/my-data-viewer
python3 -m venv .venv
source .venv/bin/activate      # Windows: .venv\Scripts\activate
pip install -r requirements.txt
python3 main.py
