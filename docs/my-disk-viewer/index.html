My Disk Viewer

Point it at a folder and see real, on-disk usage — not just apparent size — broken down by subfolder or by file type. Drill down with a breadcrumb trail to find the exact thing worth deleting, then reveal it in your file manager. It's strictly read-only: it never deletes anything itself.

Features

Real, on-disk usage — not apparent size

A scan reports actual allocated disk usage recursively, the same number du would give you, instead of the misleading apparent size a plain file listing shows.

Breadcrumb drill-down navigation

A clickable path breadcrumb sits above the table — every ancestor segment jumps straight back to it — and double-clicking a folder row (or the Up button) moves you further down or back up the tree.

Sortable spreadsheet-style table

Click any column header — Name, Type, Size, % of Folder, Items — to sort by it, click again to reverse, with an arrow indicator showing the active sort.

Manual scan with live progress

Reload computes real disk usage on demand — never automatically, since even one pass is comparatively expensive — with a live "Scanning... (n/total)" indicator as per-subfolder jobs finish.

Instant cached reopen

Every scanned folder's sizes are cached locally, so reopening or navigating back into it shows the last-known breakdown immediately — no need to rescan just to look again.

Pie chart — by folder or by file type

Toggle the Chart tab between the current folder's immediate children and a recursive breakdown by file extension (.mp4, .log, .jpg...) — useful for spotting which file type is really dominating.

Reveal in File Manager — strictly read-only

The app never deletes anything itself. Select a file or folder and click "Reveal in File Manager" to open its location in Finder, Explorer or your file manager, and act on it yourself.

Quick start

Grab a binary above, or run it from source.

git clone https://github.com/cancerberoSgx/desktop-app-samples.git
cd desktop-app-samples/my-disk-viewer
python3 -m venv .venv
source .venv/bin/activate      # Windows: .venv\Scripts\activate
pip install -r requirements.txt
python3 main.py
