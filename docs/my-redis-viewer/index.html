Features

Connection profiles

Organize Redis connections into profiles and switch the active one instantly — everything else in the app is scoped to whichever profile is active.

One-click reachability check

"Connect" opens a real connection and issues a PING, reporting success or the exact connection error — no terminal, no redis-cli needed just to sanity-check a host/port/password.

Browse the whole keyspace as a tree

Colon-delimited keys (doc:foo:bar) are rendered as an expandable branch tree, built once from a background scan and then browsed with no further round-trips.

Search by pattern and type

Filter by a Redis glob pattern (doc:foo:*) and/or a key type (string, hash, list, set, zset, stream), with debounced live search as you type.

Key details at a glance

Type, TTL, encoding, memory footprint, idle time, and the value itself — with a hex preview fallback for binary values like vectors.

Saved command scripts

Write, save, and re-run redis-cli-style command sequences per connection — run the whole script or just the current selection.

Syntax-highlighted editor, structured results

The script editor highlights commands, quoted strings and # comments with line numbers. Each command's output renders in its own block — errors in red — and any result that's a flat key list gets a "View keys..." button straight into the key browser and Key Details dialog.

Quick start

Grab a binary above, or run it from source.

git clone https://github.com/cancerberoSgx/desktop-app-samples.git
cd desktop-app-samples/my-redis-viewer
python3 -m venv .venv
source .venv/bin/activate      # Windows: .venv\Scripts\activate
pip install -r requirements.txt
python3 main.py
