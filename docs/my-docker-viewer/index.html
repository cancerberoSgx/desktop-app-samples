My Docker Viewer

A desktop GUI for admin'ing local Docker: see every container's status, live CPU/memory, and real disk footprint at a glance, then stop, start, remove or clean up containers, images, volumes and networks — without memorizing docker CLI flags. No Docker SDK, no Engine API — it shells out to whatever docker binary is already on your PATH.

Features

Live container list, filterable and sortable

Every container, running and stopped, with name, image, status, created date, size and live CPU%/memory usage — filter by name, image or status, and click any column header to sort.

Start, stop and remove with instant feedback

Start a stopped container, stop a running one, or remove any of them (with a force-remove confirmation while it's still running) — the list updates immediately instead of waiting on a reload.

Container Details in one popup

Double-click any container for its full identity, live CPU/mem, published ports, attached networks, and computed disk usage — writable layer plus every mount — without leaving the list.

Containers Disk — what's really eating space

A dedicated screen lists every container's writable layer and mounted volumes/binds, computed on demand via a disposable helper container, with a combined total and a "(shared)" flag for mounts used by more than one container.

Images: status, cascading remove, prune

See every image's In use / Unused / Dangling status. Removing an image still referenced by containers offers "image only" or "image + its containers/volumes/networks" — showing exactly what's kept vs. deleted — plus one-click pruning of dangling or unused images.

Volumes & networks: who's actually using it

Unlike raw docker volume/network ls, both screens show which containers and images actually reference each entry, refuse to force-remove something still in use (explaining why instead), and offer one-click pruning of anything unused.

No Docker SDK — just the CLI you already have

Every action shells out to the docker binary on your PATH and parses its JSON output — nothing to configure, no API version to pin, no separate daemon client library to install.

Quick start

Grab a binary above, or run it from source.

git clone https://github.com/cancerberoSgx/desktop-app-samples.git
cd desktop-app-samples/my-docker-viewer
python3 -m venv .venv
source .venv/bin/activate      # Windows: .venv\Scripts\activate
pip install -r requirements.txt
python3 main.py
